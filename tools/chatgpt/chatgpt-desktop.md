## Plugins

| Plugin | 用途 |
|--------|------|
| **Superpowers** | 规范开发流程，包括需求梳理、方案设计、TDD、调试、Code Review 和完成前验证。 |
| **Metabase** | 连接并查询 Metabase，辅助数据探索和 Dashboard 分析。 |
| **Data Analytics** | 用于数据质量检查、KPI 设计、指标诊断、分析报告和数据可视化。 |
| **Chrome** | 操作当前 Chrome 会话，查看已登录页面、执行网页操作并收集页面证据。 |
