# macOS 自定义短语（文本替换）

设置位置：系统设置 → 键盘 → 文本输入 →「文本替换…」。数据随 iCloud 同步到 iPhone / iPad。

命名规则：统一 `ai` 前缀 + 用途拼音首字母，全小写，不与真实英文单词冲突。

## 速查表

| 短语键 | 用途 |
| --- | --- |
| `aizj` | 总结全文（核心主题 + 观点事实） |
| `aijj` | 讲解全文，保留细节，像上课一样 |
| `aimkx` | 麦肯锡结构化深度总结（带数据洞察） |
| `aifs` | 核心观点 + 反思 + 评论，去 AI 味 |
| `aizyl` | 说出「注意力」看到了什么 |
| `aimg` | 美股每日收盘总结 |
| `aixw` | 新闻热点简报 |
| `aiyj` | 邮件解读 |

## aizj — 总结全文

请你仔细阅读全文，总结文章核心主题，以及主要观点和事实，越详细越好。

## aijj — 讲解全文

请你仔细阅读全文，然后像老师给我上课一样讲解一遍。要求：先用一段话说清楚它在讲什么、为什么值得关注；再按原文的逻辑顺序逐段拆解，每一部分都保留具体细节（数据、案例、时间、人物、结论）；遇到专业术语先解释清楚再往下讲，必要时打比方；最后指出容易被误解或忽略的地方，以及我应该记住的几个要点。不要泛泛而谈，不要跳过细节。

## aimkx — 麦肯锡结构化总结

请你先阅读全文，然后认真思考文章内容，提取核心主题，主要观点和事实的框架，接着在对这些内容进行反思，最终总结全文，越详细越好，采用麦肯锡地结构化表达方法写出来，以及注意尽量有数据支撑和数据洞察。

## aifs — 观点 / 反思 / 评论

请你仔细阅读文章，理解文章所要表达的客观内容，最终将｛核心观点｝，｛内容的反思｝，｛客观评论｝分段落撰写出来，撰写风格要去 AI 化，符合人类习惯。

## aizyl — 注意力机制

请你阅读全文，花一些时间认真思考，然后告诉我你的注意力机制都看到了什么，罗列出来。

## aimg — 美股总结

请提供2025年x月x日美东时间的美股总结，涵盖以下内容：主要股指的涨跌情况，包括NASDAQ、DJIA、S&P 500、QQQ、IWM和VIX指数，分别的成交量数据，重要的美债收益率（如10年期国债收益率），黄金、原油价格及期货的变化率，所有数据展示清晰有序，简洁明了，高效概括，并添加必要的图表以便直观呈现数据。

## aixw — 新闻简报

最近有什么新闻和热点，罗列出一些简短的简报，并带上时间信息。

## aiyj — 邮件解读

阅读邮件内容，并向我解释清楚
